# 완성도 이슈 목록

> 핵심 기능 구현 완료 후 남은 폴리시/버그 항목.
> 발견 즉시 여기에 추가. GitHub Issue로 옮길 때 항목 옆에 `#이슈번호` 표기.

---

## GitHub Issues 사용법

### 이슈 등록
GitHub 저장소 → **Issues** 탭 → **New issue**
- **Title**: 한 줄 요약 (예: `[Animation] 손 IK 미완 — 총 파지 위치 부정확`)
- **Body**: 재현 조건, 스크린샷, 예상 원인 등 자유 기술
- **Labels**: 카테고리 태그 달기 (아래 권장 라벨 참고)
- **Assignees**: 본인 지정

### 권장 라벨

| 라벨 | 용도 |
|------|------|
| `bug` | 잘못 동작하는 것 |
| `polish` | 동작은 하지만 완성도 미달 |
| `animation` | 애니메이션/IK 관련 |
| `network` | CMC/복제/지연 관련 |
| `combat` | 전투/무기 관련 |

### 커밋과 연동
커밋 메시지에 이슈 번호를 포함하면 GitHub에서 자동으로 연결됨:
```
Fix hand IK grip position for rifle

Closes #3
```
`Closes #번호` → 커밋이 main에 머지될 때 이슈 자동 닫힘
`Ref #번호` → 연관만 표시, 자동으로 닫히지 않음

### 흐름 요약
```
POLISH.md에 메모
  → 작업할 항목 GitHub Issue 등록
  → 수정 후 커밋 메시지에 "Closes #번호"
  → 머지 시 이슈 자동 종료
  → POLISH.md 항목에 [x] 체크
```
