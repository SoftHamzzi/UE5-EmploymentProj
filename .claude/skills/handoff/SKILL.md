# 인수인계: $ARGUMENTS

이 세션에서 작업한 영역의 `DOCS/Notes/NN/Status/NN_<영역>_STATUS.md`를 갱신한다. 여러 영역을 건드렸으면 각각 갱신한다.

## 1. 인수인계 칸 (STATUS 위쪽, 덮어쓴다)
| 항목 | 쓰는 법 |
|---|---|
| 갱신 | 오늘 날짜, 이 세션 이름 |
| 지금 단계 | 설계 / 검토 / Step NN 중 어디이고 어떤 상태인지 |
| **다음 행동** (하나) | `/session-start <역할> <영역> <대상>` 형식. 개발이면 가이드 레벨(L1~L3)을 함께 적는다 |
| 하지 말 것 | 이 세션에서 실패한 시도와 이유, 아직 금지인 것(미승인 설계 등). 이전 항목 중 여전히 유효한 것은 남긴다 |
| 근거 | 파일 경로, 커밋, PIE 확인 내용 |
| 막힌 점 / 사용자 확인 필요 | 사용자가 답해야 다음으로 갈 수 있는 것 |

## 2. 함께 확인할 것
- **Step STATUS가 코드와 맞는지.** 맞지 않으면 코드를 읽고 대조해 고친다. 추측으로 채우지 않는다.
- 결정이나 `제안`이 생겼으면 영역 DECISIONS(`NN_<영역>_DECISIONS.md`)에 있는지.
- 미룬 것이 `DOCS/BACKLOG.md`에 이유와 함께 있는지.
- Notes 문서를 크게 고쳤으면 `notes-review`를 돌렸는지.

## 3. 보고
갱신한 파일과 "다음 행동"을 보여준다. 커밋되지 않은 변경이 있으면 알린다.
