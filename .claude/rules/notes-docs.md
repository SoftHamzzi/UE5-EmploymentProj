# Notes · Mine 문서 규칙

- 문서를 새로 쓰거나 크게 고칠 때마다 `notes-review` 스킬을 쓴다 — 요청받지 않아도 기본으로 한다.
- 구현서 = 정답지. 상세하게 쓰되 사용자는 리뷰 전까지 열지 않는다. 사용자가 코딩하며 보는 것은 `Guide/`의 가이드다.
- 가이드 레벨(L1~L3), 불변식·도구 목록 쓰는 법, 자기 점검 형식, 문서 이름 규칙은 `DOCS/ROADMAP.md` §6.
- 영역 Design은 지금 유효한 설계만, 결정 경위와 버린 대안은 `NN_<영역>_DECISIONS.md`(추가만), 진행 상황은 STATUS.
- 개발·리뷰 세션에서 설계를 바꿔야 하면 DECISIONS에 `제안` 항목을 쓰고 멈춘다.
- STATUS의 Step 완료 여부는 코드를 읽고 대조해서만 갱신한다.
